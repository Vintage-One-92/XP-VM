# WHAT IS XP-VM
XP-VM is an independent project that tries to create a mini Windows XP virtual machine, without installing anything, and with the most compact and iconic WinXP version: Windows XP Professional. It includes all the Office pack, Microsoft Dance, and more. Supports 60 fps, HD, or Classic.
